# Employee Task Management System with SLA Tracking

## Objective
To manage employee tasks, track working hours,
and monitor Service Level Agreement (SLA) deadlines.

## Features
- Employee login
- Task assignment
- Task status tracking
- Work-hour logging (1–12 hours)
- SLA monitoring
- High-priority task SLA limit of 4 hours
- Task reports

## Technologies
- Python
- Git
- GitHub

## Version
1.0
